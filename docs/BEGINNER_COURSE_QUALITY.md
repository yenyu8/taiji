# 初学者课程质量要求

参考：https://github.com/redmaplewww/learn-everything/blob/main/learning_ext/progress/study.py 的 generate_node_summary。它明确要求分层讲解、类比、完整示例、运行前提、误区和附答案自测；提示要求约2000–4000字。这里描述的是该函数的提示策略，不能据此断言项目所有内容经验证正确。

太极过去只有简短的教程提示，没要求示例解释和预期输出。现改为独立实现的结构化教材协议：

- 类比 + 术语解释 + 详细讲解 + 至少三个操作步骤。
- 两至三个独立Python示例，每个包含如何操作、关键代码解释、预期输出。
- 至少两条具体错误排查、两层提示、两道带答案自测。
- 练习从讲过的例子改动开始；不得默认「会用AI」等于「会编程」。
- 当前页面不支持多文件、Shell、pip或input，不得要求创建cli.py再运行命令。
- cli.py不是特殊语法：CLI指用文字命令操作程序的界面，cli是作者选择的文件名，.py表示Python源文件。本页面直接使用右侧编辑器。

生成先做结构校验，再用AST仅解析示例语法（不在主进程执行）；拒绝省略实现、交互input、无print输出的例子。语法通过不代表逻辑正确，预期输出仍需要在编程台运行验证。不能自动证明所有术语解释充分或教材教学有效。

每次教程最多一次上游请求、输出参数上限8000 Token、总等待120秒。失败保留原教程和代码，不自动增加请求。已有教程须用户主动重新生成；示例讲解、预期输出、提示和自测随学习文件保存。

下一步人工抽查：零基础函数/字典、CLI概念、模拟工具调用三种课，检查读者能否解释每个新词、独立运行示例、完成一处修改。尚未以真实模型生成结果证明全面达到这些标准。
