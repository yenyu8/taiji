# 当前里程碑：模型连接与路线生成

## 范围

先完成普通用户自行使用：选择服务商 → 粘贴密钥 → 选择模型 → 验证 → 填目标、基础、每周时间和偏好 → 获取路线 → 调整/保存/导入。

本轮没有扩展专家平台或行业资料检索；它们是后续路线来源，不应在当前版本标成已实现。

## 生成策略 v0.3

1. 参考 Learn Everything 的结构化阶段/节点/前置依赖及二次审查，独立实现。
2. 每节必须包含学习成果、实践任务、完成标准和预计时间。通常8至18节，允许3至30节，每节0.5至4小时。
3. 校验阶段顺序、前置节点顺序、循环、缺失引用、重复标题、空阶段和实践字段。
4. 格式或质量门槛不通过时自动修正一次；仍失败则明确报错，不产生假路线。
5. 第二轮模型复核补齐内容并返回改动和待确认问题。复核失败保留有效初稿，并标注未复核。所有生成最多330秒，无无限重试。
6. 时间按节点估算汇总，每周时间用于计算学习周期，不承诺完成日期。
7. 修改意见与原路线一同发送，候选路线预览后才采用；采用时备份上一版，可恢复。

所有模型复核都是建议，不代表专家认证。标准库沙箱的能力限制写入生成提示，涉及联网/第三方依赖用明确标注的模拟练习。

## 验收情况

已自动验证：模型列表/鉴权模拟、令牌参数兼容、错误脱敏、格式修复、复核失败回退、学习顺序门槛、调整上下文、导出字段与来回导入。后端18项通过；前端测试与生产构建通过。

待真实验证：用户提供的模型账号能否连接、实际路线内容质量、浏览器完整交互。浏览器自动控制工具此前故障，不能把HTTP/模拟测试当成真实用户验收。

## 人工验收步骤

- 在页面填入真实API Key（不要提交到仓库或聊天），确认模型下拉列表出现。
- 点击连接并继续；错误密钥应给提示而非进入下一步。
- 用目标「做一个能调用天气工具的Agent」、零基础、每周3小时生成，检查基础前置、练习可做、完成标准可检查。
- 再试已有编程基础，确认路线不是同一套机械模板。
- 提出「多举例、减少理论」，预览后采用；确认可恢复上一版及其代码。
- 导出、刷新、导入，检查完成标准、路线复核说明和用户代码仍在。

## 后续质量提升

积累匿名测试案例（不保存密钥和用户私密内容），针对失败类型改提示和校验；以后可把专家或行业资料作为可追溯来源接入同一结构。专家审核应记录审核人、范围和版本；行业资料应记录出处和适用日期。这些均未在本轮实现。

## 费用与等待控制（更新）

路线任务总等待上限改为180秒。默认生成+复核最多2次上游请求；格式修正默认关闭，可明确勾选后增加1次。接口令牌参数兼容重试也计入同一预算。生成/修正的输出参数上限各6000，复核8000，不代表总账单上限（还包含输入及服务商具体计费）。

本地进度接口显示阶段、次数与时间，不调用模型。支持显式停止、页面离开取消通知和后端断线检测，同一连接不允许并行路线任务。停止会取消本地上游连接和后续调用，无法保证服务商停止已经接收的推理或退款。没有自动整任务重试。

取消、超时、重复提交、默认不修复和兼容重试预算已有自动测试；当前后端21项通过。真实服务商的停止计费行为未验证。
